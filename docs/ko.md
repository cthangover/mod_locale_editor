# 번역 — 언어에 없는 텍스트를 입력하기

번역 창은 어떤 언어에 모드별로 없는 텍스트를 모두 보여 주고, 입력한 번역을 그 텍스트를 가진 모드의 현지화 파일에 씁니다. 게임은 새 텍스트를 바로 보여 줍니다. 게임 안의 도구 모음에 있는 **번역** 버튼으로 엽니다. 개발자 도구가 든 게임(`cthangover`)과 `rpg_plus`에 있습니다.

## 열기

게임을 시작하고 도구 모음에서 **번역**을 고릅니다. 창은 설치된 모든 모드의 현지화 파일을 읽습니다. 몇 초 뒤 없는 텍스트 개수를 보여 줍니다.

## 텍스트 번역하기

1. 왼쪽 위에서 **언어**를 고릅니다(예: `ko`). 목록에는 그 언어에 없는 텍스트만 나옵니다.
2. 원하면 **모드**를 하나 골라 그 모드의 텍스트만 봅니다.
3. 왼쪽의 행을 클릭합니다. 오른쪽에 다음이 나옵니다.
   - **키** — 게임이 요청하는 식별자(예: `rpg_plus/map/village`);
   - **모드** — 텍스트를 가진 모드;
   - **파일** — 이 줄이 들어갈 현지화 파일(예: `locale/ko.properties`);
   - **다른 언어의 텍스트** — 영어나 러시아어의 같은 텍스트(또는 시나리오의 원문)를 힌트로 보여 줍니다.
4. 번역을 입력하고 **저장**을 누릅니다(Enter나 Ctrl+S도 됩니다). 줄이 파일에 쓰이고, 게임이 텍스트를 다시 읽으며, 그 행은 목록에서 사라집니다. **다시 검사**를 누르면 파일을 한 번 더 읽습니다.

파일에서는 한 줄만 바뀝니다. 다른 키, 주석, 줄바꿈은 그대로 남습니다.

## 텍스트가 들어가는 곳

- 모드의 다른 언어에 선언된 키는 이 언어의 같은 파일에 들어갑니다: `ui_en.properties` → `ui_ko.properties`; `en.properties` → `ko.properties`.
- 시나리오가 쓰지만 어느 파일에도 선언되지 않은 키는 모드의 `scenarios_<언어>.properties`에 들어갑니다.
- zip 모드는 읽기 전용입니다. 그 행은 보이지만 **저장**이 꺼져 있고 창이 그렇게 알려 줍니다. 번역하려면 모드를 모드 폴더로 복사하세요(폴더형 모드는 쓸 수 있습니다).

## 텍스트가 없는 이유

창은 스스로 판단하지 않습니다. 현지화 아틀라스(`locale_atlas`)가 찾은 것을 보여 줄 뿐입니다. 아틀라스가 검사기이며, 모든 경고가 든 전체 보고서는 `tests/artifacts/locale_atlas/report.md`에 있습니다(개발자용). 없는 번역은 빈칸이지 빌드 고장이 아닙니다. 게임은 텍스트가 있는 언어를 보여 줍니다.

## 알아 두면 좋은 것

- 스캐너는 현재 게임 밖의 모드를 포함해 발견된 모든 설치 모드와 컬렉션 패키지를 검사합니다. 로드된 모드를 로드 순서로 먼저 검사합니다. 읽기 전용 소스는 볼 수 있지만 저장할 수 없습니다.
- **새 모드**(모드 관리자)로 만든 모드는 제목이 영어와 플레이어의 언어로 시작합니다. 다른 언어의 제목은 여기에 없는 텍스트로 나타납니다.
- 이미 선언된 텍스트는 나오지 않습니다. 번역을 바꾸려면 파일을 고치거나 아이템·캐릭터 편집기를 쓰세요(이름은 각 양식에서 언어별로 입력합니다).
