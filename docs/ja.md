# 翻訳 — 言語に不足しているテキストを入力する

翻訳ウィンドウは、ある言語が MOD ごとに不足しているテキストをすべて一覧し、入力した訳文をそのテキストを持つ MOD のローカライズファイルに書き込みます。ゲームはすぐに新しいテキストを表示します。ゲーム内のツールバーの「翻訳」ボタンから開きます。開発者ツールを含むゲーム（`cthangover`）と `rpg_plus` にあります。

## 開く

ゲームを起動し、ツールバーで「翻訳」を選びます。ウィンドウはインストール済みのすべての MOD のローカライズファイルを読みます。数秒後に不足しているテキストの件数が表示されます。

## テキストを翻訳する

1. 左上で**言語**を選びます（例：`ko`）。一覧にはその言語に不足しているテキストだけが出ます。
2. 必要なら **MOD** を 1 つ選び、その MOD のテキストだけを表示できます。
3. 左の行をクリックします。右側に次が表示されます：
   - **キー** — ゲームが要求する識別子（例：`rpg_plus/map/village`）；
   - **MOD** — テキストを持つ MOD；
   - **ファイル** — 行が書き込まれるローカライズファイル（例：`locale/ko.properties`）；
   - **他の言語のテキスト** — 英語またはロシア語の同じテキスト（シナリオの原文）をヒントとして表示。
4. 訳文を入力して**保存**を押します（Enter または Ctrl+S でも可）。行がファイルに書き込まれ、ゲームがテキストを読み直し、行が一覧から消えます。**再スキャン**でファイルを読み直せます。

ファイルで変わるのは 1 行だけです。他のキー、コメント、改行はそのまま残ります。

## テキストの書き込み先

- MOD の他の言語で宣言されたキーは、この言語の同じファイルに入ります：`ui_en.properties` → `ui_ko.properties`、`en.properties` → `ko.properties`。
- シナリオが使っていてどのファイルにも宣言されていないキーは、MOD の `scenarios_<言語>.properties` に入ります。
- zip の MOD は読み取り専用です。行は表示されますが、**保存**は使えず、ウィンドウがその旨を示します。翻訳するには MOD を MOD フォルダーにコピーしてください（フォルダー形式の MOD には書き込めます）。

## テキストが不足する理由

ウィンドウ自体は判断せず、ローカライズアトラス（`locale_atlas`）が見つけたものを表示します。アトラスが検査役で、警告を含む完全なレポートは `tests/artifacts/locale_atlas/report.md`（開発者向け）にあります。翻訳の不足は隙間であり、ビルドの破損ではありません。ゲームはテキストがある言語を表示します。

## 知っておくと良いこと

- 検出済みのインストール MOD とコレクションをすべて調べ、実行中のゲームに含まれないものも対象です。読み込み済み MOD をロード順で先に調べます。読み取り専用の情報は確認できますが保存できません。
- 「新しい MOD」（MOD マネージャー）で作った MOD は、タイトルが英語とプレイヤーの言語で始まります。他の言語のタイトルは、ここに不足として現れます。
- 既に宣言されたテキストは出てきません。翻訳を変えるにはファイルを編集するか、アイテムやキャラクターのエディターを使ってください（名前は各フォームで言語ごとに入力します）。
