# 翻译 — 填入某种语言缺少的文本

翻译窗口列出某种语言在各模组中缺少的所有文本，并把你输入的译文写入拥有该文本的模组的本地化文件。游戏会立即显示新文本。它从游戏内工具栏的**翻译**按钮打开；包含开发者工具的游戏（`cthangover`）和 `rpg_plus` 中都有此按钮。

## 打开

启动游戏，打开工具栏并选择**翻译**。窗口会读取所有已安装模组的本地化文件；几秒钟后显示缺失文本的数量。

## 翻译一条文本

1. 在左上角选择**语言**（例如 `ko`）。列表只显示该语言缺少的文本。
2. 如需要，可选择一个**模组**，只查看它的文本。
3. 点击左侧的一行。右侧显示：
   - **键** — 游戏请求的标识，例如 `rpg_plus/map/village`；
   - **模组** — 拥有该文本的模组；
   - **文件** — 这一行将写入的本地化文件，例如 `locale/ko.properties`；
   - **其他语言的文本** — 同一文本的英文或俄文（或剧本使用的原文）作为提示。
4. 输入译文并点击**保存**（或按 Enter、Ctrl+S）。该行写入文件，游戏重新读取文本，该行从列表中消失。点击**重新检查**可再次读取文件。

文件中只改动这一行：其他键、注释和换行符保持原样。

## 文本写到哪里

- 在模组其他语言中声明的键，写入该语言的同名文件：`ui_en.properties` → `ui_ko.properties`；`en.properties` → `ko.properties`。
- 剧本使用但没有任何文件声明的键，写入模组的 `scenarios_<语言>.properties`。
- zip 模组是只读的。它的行会列出，但**保存**不可用，窗口会说明原因。要翻译它，请把模组复制到模组文件夹（文件夹形式的模组可以写入）。

## 为什么缺少文本

窗口本身不做判断，它只显示本地化图谱（`locale_atlas`）找到的内容。图谱是检查工具；完整报告（含所有警告）位于 `tests/artifacts/locale_atlas/report.md`（仅供开发者）。缺少译文只是空缺，不是构建损坏：游戏会显示有该文本的语言。

## 需要知道

- 扫描器包含所有发现的已安装模组与合集包，包括当前游戏之外的模组。已加载模组按加载顺序优先扫描；只读来源可查看但不能保存。
- 用模组管理器的**新建模组**创建的模组，标题会先用英文和玩家语言写入；其他语言会作为缺失的标题出现在这里。
- 已经声明的文本不会出现。要修改译文，请编辑文件，或使用物品或角色编辑器（它们的名称在各自表单中按语言填写）。
