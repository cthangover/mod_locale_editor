# Переводы — впишите тексты, которых не хватает языку

Окно переводов показывает все тексты, которых языку не хватает в каком-либо моде, и записывает введённый перевод в
файл локализации того мода, которому принадлежит текст. Игра сразу показывает новый текст. Окно открывается кнопкой
**Переводы** на панели инструментов в игре; в играх с инструментами разработчика (`cthangover`) и в `rpg_plus` кнопка есть.

## Открыть

Запустите игру, откройте панель инструментов и выберите **Переводы**. Окно прочитает файлы локализации всех установленных
модов; через несколько секунд оно покажет число недостающих текстов.

## Перевести текст

1. Выберите **язык** слева вверху (например, `ko`). В списке будут только тексты, которых этому языку не хватает.
2. При желании выберите один **мод**, чтобы видеть только его тексты.
3. Щёлкните строку слева. Справа показано:
   - **Ключ** — идентификатор, который спрашивает игра, например `rpg_plus/map/village`;
   - **Мод** — мод, которому принадлежит текст;
   - **Файл** — файл локализации, куда попадёт строка, например `locale/ko.properties`;
   - **Текст на другом языке** — тот же текст по-английски или по-русски (или буквальный текст сценария) как подсказка.
4. Впишите перевод и нажмите **Сохранить** (или Enter, или Ctrl+S). Строка записывается в файл. Игра перечитывает
   тексты, строка исчезает из списка. Кнопка **Проверить заново** читает файлы ещё раз.

Файл меняется только в одной строке: остальные ключи, комментарии и переводы строк остаются как были.

## Куда попадает текст

- Ключ, объявленный в других языках мода, попадает в файл этого языка: `ui_en.properties` → `ui_ko.properties`;
  `en.properties` → `ko.properties`.
- Ключ, который использует сценарий, но который не объявлен ни в одном файле, попадает в `scenarios_<язык>.properties`
  мода.
- Мод из zip-архива только для чтения. Его строки видны, но **Сохранить** выключена, и окно это говорит. Чтобы перевести
  такой мод, скопируйте его в папку модов: папочные моды можно записывать.

## Почему текст не хватает

Окно ничего не решает само: оно показывает то, что находит атлас локализации (`locale_atlas`). Атлас — проверяющий;
полный отчёт со всеми предупреждениями лежит в `tests/artifacts/locale_atlas/report.md` (для разработчиков). Недостающий
перевод — это пробел, а не поломка сборки: игра показывает язык, у которого текст есть.

## Полезно знать

- Сканер включает все обнаруженные установленные моды и пакеты коллекций, в том числе вне текущей игры. Загруженные моды идут первыми в порядке загрузки. Источники только для чтения можно просмотреть, но нельзя сохранить.
- Новый мод, созданный кнопкой **Новый мод** (менеджер модов), получает название по-английски и на языке игрока;
  остальные языки появятся здесь как недостающие названия.
- Уже объявленные тексты не предлагаются. Чтобы поменять перевод, отредактируйте файл или используйте редактор предмета
  или персонажа (их имена вписываются по языкам в своих формах).
